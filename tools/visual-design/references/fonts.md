# 字体体系

**字体先在渲染环境中安装，fontFamily 使用该环境识别的准确 family 名。** 本地导出器写入字体名，不下载或嵌入字体；交付前检查实际渲染是否发生字体替换。

三类字体来源，均需确认可用：

## 1. Google Fonts

从字体提供方获取并安装到渲染环境，再使用准确 family 名。例如：

```yaml
fontFamily: "JetBrains Mono"     # 等宽，需先安装
# 其他可选：Archivo Black（超粗无衬线）、EB Garamond（古典衬线）
```

## 2. 系统字体（直接用，无需声明）

`fontFamily` 写**标准名**即可；别名指向同一字体但不要写进 fontFamily。

| 标准名 | 常见别名 |
|---|---|
| 微软雅黑 | Microsoft YaHei, MS YaHei, 雅黑 |
| 等线 | DengXian |
| 黑体 | SimHei, Hei |
| 宋体 | SimSun, 中易宋体 |
| 华文黑体 | STHeiti, Heiti SC |
| 华文宋体 | STSong |
| 思源黑体 | Source Han Sans, Noto Sans CJK SC, Noto Sans SC |
| 仿宋 | FangSong, 仿宋_GB2312 |
| 楷体 | KaiTi, 楷体_GB2312 |
| 方正小标宋简体 | 方正小标宋, FZXiaoBiaoSong-B05S |
| Calibri / Arial / Helvetica / Helvetica Neue | — |
| Times New Roman | Times, TNR |
| Georgia | — |

注意：系统字体太常见、风格不鲜明。除非用户点名，**优先用 Google Fonts 和 CDN 字体**，别拿系统字体凑数。

## 3. 外部字体选项（须先安装）

以下保留字体选型参考，不表示这些字体已安装或随技能提供。获取字体时遵循提供方的使用许可，并在渲染环境中核对 family 名；不使用 `customFonts` 声明代替安装。

```yaml
fontFamily: "LXGW Bright"
```

## 搭配原则

- 一款有性格的展示字体（标题/大数字）+ 一款精致的正文字体，是最稳妥的高级感配方。
- 默认字体（思源宋体、Arial、Inter）是平庸的信号——除非风格刻意为之，否则选有个性的。
