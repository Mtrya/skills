# 设计资产工作流

用 `.pptd`（YAML 设计语法）构建设计资产。先读 [pptd-spec.md](pptd-spec.md) 掌握语法与本地支持范围——导出器支持的文本和预置形状优先用原生定义，保持产物可编辑；超出能力的（自定义路径、抠图、调色曲线、复杂图形）先用合适的图像工具处理成素材再嵌入，**绝不直接降级交付**。

## 五步工作流

### 第 1 步：读透上下文
读完用户上传的全部文件、URL 和 `pptd-spec.md`。需要大量重复规则元素（平铺纹理、像素块）时，用 Python 计算坐标批量生成，不手排。

以下情况先用 ask 工具问清：需求模糊、文件打不开、意图冲突（如要麦肯锡风又要大面积留白、要 10 页又要 30+ 页）、无法自行判断用途/风格/页数。

### 第 2 步：收集素材

任务涉及具体品牌或产品时（"给 Stripe 做提案"、"Pocket 4 发布会视觉"），走**品牌资产协议**——通过官方渠道确认六类资产并存到 `media/`：
1. Logo  2. 产品图  3. UI 截图  4. 品牌色  5. 字体  6. 设计规范

### 第 3 步：按类型生成

先读 [profiles.md](profiles.md) 中对应场景的完整规范：

| 类型 | 典型需求 |
|---|---|
| 海报 poster | 艺术海报、品牌海报、活动宣传 |
| 信息图 infographic | 数据可视化长图 |
| 社媒内容 social-media | 小红书/Instagram/公众号等配图与封面 |
| 文档 document | 简历、文档、无插画菜单 |
| 产品图 commodity | 产品主图、产品宣传页 |
| 其他 others | 兜底场景 |

所有场景共享一个核心仪式——**先规划后生成**：
1. 规划阶段：给主题列 1–3 个质感关键词（蓝图、版画、齿轮、胶片、水墨、砂岩、羊皮纸、铸造……），然后**自己命名一个风格**（可融合经典风格，也可全新发明），用两三句话描述风格特征；配字体（有性格的展示字体+精致的正文字体，远胜思源宋体/Arial/Inter 这类默认款）；定配色（清晰有主次，远胜平均铺色）；设计出人意料的版式（错位栏、跨栏标题、图文交叠、图片破框、偏心视觉焦点、大留白、疏密对比）；列出核心视觉元素的设计要求——全部逐行写进 `style.md`。
2. 生成阶段：按 style.md 和 pptd 语法完成作品；擅长图像处理，让图片元素融入整体设计；必要时根据素材修订 style.md。

**通用红线**
- 作品必须是顶级设计师水准，平庸方案不可接受。
- 多次生成之间切换明暗主题、字体和美学风格，**绝不收敛到同一个方案**。
- 文字必须清晰易读简洁，不主动添加可有可无的文字。
- 氛围与层次技法：渐变混合色块、细腻颗粒纹理、疏密变化的几何图案、半透明色彩叠层、有纵深感的阴影、克制的装饰边框。

**尺寸**：用户指定就严格照办；未指定按场景选常用尺寸——16:9 `[1280,720]`、9:16 `[720,1280]`、4:3 `[1280,960]`、3:4 `[960,1280]`、1:1 `[1080,1080]`；信息图默认宽 1080 竖长图。

**复刻任务**：分析原图估算元素位置、字体、字号，尽量 1:1 复刻；难辨认处用网格线、局部放大辅助；简单内容用元素复刻，图标可用 Font Awesome 近似，无法近似的（照片、头像）用 Python 裁剪原图后作为图片元素嵌入。**严禁把用户上传的位图整张直接贴进页面当唯一内容。**

### 第 4 步：校验
1. 跑 `python scripts/pptd_check.py <目录>` 多轮修复；该脚本检查格式和导出支持范围，溢出/欠填充需通过渲染检查；刻意出血产生的 BoundsOutside 可按设计判断，Unsupported 必须处理。
2. 导出转图检查视觉，发现问题改源文件再校验，循环到干净。

### 第 5 步：交付
交付 `.pptd` 源文件目录 + 导出的成品（pptx/png）。告诉用户如何改：编辑对应 `.page` 文件后重新导出。

## 重要规则

1. 产物写在用户指定位置或项目已有输出目录；主入口命名 `xxx.pptd`（多文件结构：主入口 + pages/ + media/，全相对路径自包含）。
2. 动画只在用户明确要求或明确用于现场演示时使用；阅读、打印、发送浏览类一律不加。本地导出器不支持动画，需要时使用相应工具编辑成品。
3. 制作时尽量并行写多个 .page 文件。
4. 字体规则见 [fonts.md](fonts.md)：字体先在渲染环境中安装，再用准确的 family 名；本地导出器不下载或嵌入字体。
