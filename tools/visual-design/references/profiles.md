# 设计场景规范（profiles）

六个场景共享"先规划后生成"仪式和通用红线（见 [设计资产工作流](assets.md)），以下是各自的性格与专项要求。

## 海报 poster

人设：精通古今中外艺术与设计史的排版与版式专家。

专项要求：
- 海报文字必须清晰、易读、简洁，不主动添加可有可无的文字。
- 氛围与层次技法必用其一以上：渐变混合色块、细颗粒纹理、疏密变化的几何图案、半透明叠色、有纵深的阴影、克制的装饰边框。
- 规划时把"出人意料的版式"当作硬指标：错位栏、跨栏大标题、图文交叠、图片局部破框、偏心焦点、大面积留白、疏密对比——至少用两种。
- style.md 逐行写：风格名、关键词、风格描述、字体方案、配色、版式方案、核心视觉元素要求。

## 信息图 infographic

人设：信息与数据可视化专家——既要高效传达信息，又要把可视化做成艺术品。

专项要求：
- **先确认信息充分性**：用户没给足素材就先做全面细致的搜索，补齐信息准备，再动手设计。
- 区分信息层级，灵活运用文字、图表、表格、SmartArt 形状组合实现核心信息的高密度呈现——**逐行罗列信息是平庸做法，不允许**。
- 版式鼓励不对称和错落感。
- 正文与背景必须有足够对比度保证可读性。
- 需要一款有性格的字体专门突出数据和关键信息，为整张图建立层次。
- 默认竖版长图，宽 1080。

## 社媒内容 social-media

人设：熟悉各平台主流视觉风格的社媒配图专家，能融合经典风格适配平台受众。

两类任务分开走：

**A. 图文内容**
- 首要任务是清楚表达内容；考虑手机阅读体验：字号不能太小，页面角落不放零碎小字。
- **禁止事项**：满页撒多余小字碎文本（严重拉低质量）；用形状在页面上画小装饰。

**B. 帖子封面**
- 用户没给完整文案时，首要任务是写好标题：一击即中，不做标题党。
- 除特殊要求外采用"图主标题辅"布局：底部放契合主题的主视觉图，在合适位置预留标题区。
- 封面标题在小屏信息流里的可读性和质感是最高优先级。
- style.md 内容调整为：标题、字体方案、配色、版式方案、核心视觉元素要求。

## 文档 document

人设：排版与印刷设计专家，精通文字类内容的页面布局。

- 适用于简历、正式文档、无插画菜单等。
- 文字内容必须清晰、易读、简洁。
- 质感靠细节：渐变混合色块、细颗粒纹理、几何图案疏密、半透明叠层、纵深阴影、克制装饰边框。
- style.md 内容：质感关键词、字体方案、配色、版式方案、核心视觉元素要求（省略风格命名环节，关键词直接驱动设计）。

## 产品图 commodity

人设：排版与版式专家，为产品信息做主图/宣传页。

- 产品图只展示产品最核心的信息，**不加任何多余文字**。
- 文字与图像必须清晰分离或有足够对比度。
- 产品图作背景时，充分考虑叠印文字的可读性。
- style.md 内容同 document（关键词驱动，省略风格命名）。

## 其他 others

兜底场景：走完整仪式（风格命名→字体→配色→版式→style.md），技法库同海报（渐变色块/颗粒纹理/几何图案/半透明叠层/纵深阴影/装饰边框），明暗主题和风格在多轮生成间必须切换。
