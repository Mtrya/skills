# Beamer 实操

## 接入现有主题

- 先编译或查看主题示例，核对版面比例、标题页、页脚、标识和中文字体。保留主题的身份元素。需要调整时，把项目特有的间距、颜色和宏放在演示文稿自己的导言区。
- 中文演示文稿可用 XeLaTeX 和 `ctexbeamer`。按模板或场地选择比例。内容页适合以固定顶部为基准时可用 `t`。封面只需要标识和作者时可用 `[plain,c]`。对照机构原始矢量图和交付 PDF 核对标识，给素材裁切边界和页面边界留出空间。
- 内容页若使用页脚，给出处与页码各留稳定位置。正文、文献和致谢的顺序按现场使用方式决定。用 `\note{...}` 保存预计用时和口头过渡。最终投影版需要隐藏备注时，检查导出 PDF 的实际页序。

## 字体与公式

- 中文常规字重可以从 Noto Sans CJK SC 或思源黑体试起。小标题或图中标签太黑时，把粗体映射到已安装的 Medium。英文可试 Fira Sans、Inter 或模板字体。根据实际字面大小调节比例。
- TeX Live 的 OpenType 数学字体可以用 `kpsewhich` 查文件。用 `unicode-math` 配 Fira Math 可以让变量接近无衬线标签，配 STIX Two Math 可以得到衬线公式。拿同一页的正文、变量和数据对照读，主要看字母辨认度、下标和笔画的相对强度。
- 变量通常用斜体，损失函数或操作符的文字名称用正体。使用 `unicode-math` 时可用 `\symup{CE}` 让正体操作符取自数学字体。数值与单位之间留适当间距，例如 `$[-1,1]\,\mathrm{m/s}$`。

## 图表与边界

- 架构图用一套共享节点样式与坐标。同一链路要用等高节点时，最小高度以最长标签及其上下内距为准。在上、下分支都需要箭头的地方提前预留线槽。监督或梯度箭头明确方向，与前向数据流分别标记。
- 需要可见边界时，可从约 0.5 pt 的描边试起。投影上看不到就增强对比度。微灰底、白色模块、浅语义填充、深色主字是可以组合的手段。颜色和线宽服从模板，并按渲染结果调整。
- 数据用 `booktabs` 排三线表，数值列可用 `siunitx` 的 `S[table-format=3.2]` 对齐小数点。最优值按指标方向强调。比例条从数值出发并共用尺度，显示降低百分比时写清相对基准。长标签给足列宽，必要时把完整术语放在 `\mbox{...}` 里。
- 浅色照片外框可用 `\fcolorbox`，令 `\fboxsep=0pt`，并从目标图宽扣除两侧边线。对齐左右栏时同时核对照片与首行文字，TeX 盒子的顶端相同仍可能出现字面高低错觉。

## 从实际导出件核对

在项目要求的工作目录编译，临时文件单独放置。以下命令以 `slides.tex` 为例。

```bash
slides_build_dir=$(mktemp -d)
latexmk -xelatex -interaction=nonstopmode -halt-on-error -outdir="$slides_build_dir" slides.tex
pdfinfo "$slides_build_dir/slides.pdf"
pdftoppm -r 140 -png "$slides_build_dir/slides.pdf" "$slides_build_dir/page"
```

- 看日志中的溢出版面和缺字提示。看整套缩略图判断节奏，再以投影尺寸看改过和受全局样式影响的页面。用 `pdftotext -layout` 抽查公式周围的文字、数据标签、页序与文献出处。
- Beamer 可能把紧接在 `\begin{frame}{标题}` 后面的裸花括号组当成副标题。若首个内容块在 PDF 中消失，在它之前显式进入正文，例如用 `\noindent` 引出分组。重新检查该块是否出现。
- 把全局内容对齐改为顶部以后，重点检查含大照片、图注和两栏的页面。以最终 PDF 里的边界为准，必要时收紧页眉的段间距或缩小图幅。提交前核对总时长、封面、最后一页，以及用户明确要求增删的页。
