# 分章写作参考

## 解析原则

动笔前，适用的决策应被**解析成具体值**，不允许带着"参见某处"式的抽象指引写作。写作前按本章需要落实下面的简报检查清单。

## 写手简报检查清单

每章开写前，确认适用的内容已就位且具体：

**① 声音与语气**（按报告类型选一套并贯彻全篇）：

| 风格 | 适用 | 要求 |
|---|---|---|
| 行业研究 | 市场/行业分析 | 数据驱动，每个论断有定量证据；先讲现状再推演含义；预测用限定词（"预计""测算"）；第三人称；无推销语气 |
| 咨询 | 咨询交付物 | 洞察导向、行动导向，"so what"先行 |
| 政策简报 | 政策类 | 简洁、循证、中立，用政策话语体系 |
| 技术报告 | 技术/工程 | 精确、方法透明、可复现导向 |

**② 引用标准**：
- 默认以来源链接紧跟相关主张；用户指定引用格式时从其要求。
- 密度：每个关键数据点、事实主张、比较性结论都必须有引用。
- 来源分级：**T1 优先**——政府网站、国际组织、顶级期刊、法定披露、权威技术文档；**T2 可用**——主流通讯社（路透/彭博/AP）、权威智库、企业官方博客；**拒用**——内容农场、匿名论坛、未核验社媒、SEO 聚合站。

**③ 图表规则**：
- 可考虑表格的场景：多个实体的对比、流程步骤、性能指标、实验数据、分类体系、评估标准、参数汇总；以便于阅读和比较为准。
- 表格样式可用浅灰表头或三线表，也可沿用已有视觉规范；引用就近标注。
- 表格分析说明影响判断的趋势、异常值和含义，字数由内容决定。
- 可考虑配图的场景：时间序列趋势、份额分布、竞品对比、财务比率走势、成本结构、预测情景；按表达需要选择。
- 图用 matplotlib/seaborn（或 ECharts 渲染为静态图）；流程/逻辑图用 Mermaid；不用 ASCII 图。
- 图注说明口径（时间段、地域、方法），来源标在图下方。

**⑤ 语言与数据规范**：
- 客观中立，不夸张、不绝对化；专业术语首次出现即定义；同一概念全文同一词；缩写首现给全称。
- 优先近 1–2 年数据，用旧数据必标年份；不确定的数据写明统计口径与方法。
- 禁止无数字的模糊量词（"显著增长"）；分析必须具体，不给泛泛建议。

**⑥ 产出规则**：
- 每段必须有具体信息点（事实/数据/分析/论证推进）；连续论证用散文，并列事项或步骤可用列表。
- 表格装结构化对比，散文做分析论证。
- 最小深度测试：删掉该段论证不受损 = 注水，重写。
- 章节末尾不写小结（大纲明确要求除外）；章节文件不附参考文献列表。

## 每章任务卡（需要分章管理时使用）

```
章节：X.X 标题 | 文件：{报告名}_sec{NN}.md | 目标字数：___

用户需求摘要：（一段话：要什么、给谁看、范围）
大纲节选：（逐字粘贴本章的结构）
上下文：第 X 章共 N 章；前一章讲了…；后一章要铺垫…
前置要点：（前序章节中本章必须呼应的数据/结论/术语）
输入材料：研究工作目录下已有的洞察文件、交叉验证文件、与本章相关的维度证据文件、
         与本章相关的用户原始材料路径（按章择要，不全量倒给）
```

## 反模式速查

| 反模式 | 修法 |
|---|---|
| "随着 XX 的快速发展……"开头 | 直接从具体事实写起 |
| "这是一个复杂的问题……" | 直接说清复杂在哪 |
| 节末"综上所述/总之" | 以前瞻性含义收束 |
| 用子弹列表代替连续论证 | 按信息关系选择表达，分析用散文 |
| "显著增长"无数字 | 给出百分比、数值、时间范围 |
| "值得注意的是……" | 删掉，直接说事 |
| "在不断演变的格局中……" | 换成具体的变化或趋势 |

## 好/坏对照

坏："电池成本显著下降，这对电动车行业是重要进展。"
好："电池成本同比下降 14% 至 139 美元/kWh（来源：…），越过电动车在中国大众市场与燃油车购置价持平的临界点——这解释了某厂商三季度 40% 的销量增长。"
