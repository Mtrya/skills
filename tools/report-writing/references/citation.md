# 引用管理参考

## 两种场景两种格式

| 场景 | 格式 | 示例 |
|---|---|---|
| 正文（大纲与各章） | 默认使用来源链接 | `[来源名称](URL或文件路径)` |
| 参考资料列表（按需） | 来源链接；指定规范时从其要求 | 描述性链接或 `[1]`、`[2]` |

- 来源链接紧跟其支持的主张，指向实际依据。
- 同一来源可支撑连续多句，但每个独立数据点都要各自标注。
- 用户指定引用格式时从其要求。

用户提供的文档、仓库文件和数据也可作为来源，链接到实际文件及必要的章节、页码或数据范围；无法链接时标明可定位的出处，不编造 URL。引用原始材料，避免仅指向临时研究目录中的摘录。

## 来源分级

- **T1（优先）**：政府官网、国际组织（联合国/世行/IMF/WHO）、顶级同行评审期刊、法定公司披露（10-K/年报）、权威技术文档。
- **T2（可用）**：主流通讯社（路透/彭博/AP/AFP）、权威报纸、公认智库与咨询机构、企业官方博客与新闻稿。
- **拒用**：内容农场、SEO 聚合站、匿名论坛、未核验社媒、无同行评审的自出版材料、无数据支撑的厂商软文。

冲突消解：同一事实多个来源取 T1；多个 T1 取最新；T1 之间打架则在正文注明分歧。

## 引用收集与汇总

需要集中管理来源时，可把引用记录追加到收集文件（如 `{报告名}_references_raw.md`）。需要参考资料列表或用户指定规范时，装配前由"引用管理"环节统一处理：

1. 读取收集文件；去重（同 URL 或同 DOI = 同一条）。
2. 默认保留来源链接；采用编号格式时，顺序编号 `[1]`、`[2]`……
3. 按用户指定格式排版（如 GB/T 7714-2015）：
   - 期刊论文优先给 DOI；
   - 网页、数据库、政府报告给 URL；
   - 图书、学位论文无唯一获取途径时可不给 URL。
4. 合入最终报告；需要独立文件时，可输出到 `{报告名}_ref.md`，只含文献列表。

编号文献示例（用户要求该格式时）：

```
[1] OICA. World Motor Vehicle Production Statistics[DB/OL]. 2024. https://www.oica.net/...
[2] 张三, 李四. 新能源汽车发展研究[J]. 汽车工程, 2023, 45(3): 120-135.
```

交付前核对来源链接；采用编号引用时，统一正文编号与文献条目。参考资料列表与正文须指向相同来源。
